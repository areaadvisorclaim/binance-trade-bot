# Публикация v1.1.0

Репозиторий: postveteranarm/binance-trade-bot.

## Что загрузить в репозиторий

Распакуй исходный архив и загрузи содержимое папки `binance-trade-bot` в корень репозитория. В корне должны находиться `README.md`, `LICENSE`, `requirements.txt` и папка `binance_trade_bot`.

Сохрани `.user.cfg.example`, `.gitignore`, `data/.gitignore` и `logs/.gitkeep`. Перенос через Git или GitHub Desktop помогает сохранить скрытые файлы.

Не загружай этот ZIP в репозиторий вместо распакованных файлов: он не распакуется автоматически. Не публикуй личный `user.cfg`, API-ключи, базы данных и логи.

## Что прикрепить к релизу

Отдельно подготовь архив с названием **BinanceTradeBot**, внутри которого находится твой **BinanceTradeBot-Windows-x64.exe**. Фактическое расширение архива зависит от выбранного формата; README указывает его базовое имя без предположения о формате.

Если сборке нужны конфигурационные файлы или дополнительные ресурсы, включи их в архив. Для исходного формата настроек нужны шаблон `user.cfg.example`, список `supported_coin_list` и рабочие папки `data`, `logs`, `config`. Личные ключи в комплект не включай.

После распаковки пользователь запускает приложение двойным щелчком по EXE. Скрипты подготовки релиза не нужны пользователю для запуска приложения.
