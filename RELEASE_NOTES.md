# Binance Trade Bot for Windows v1.1.0 — Independent Build

Independent Windows distribution based on the open-source Binance Trade Bot project.

## Download and launch

1. Expand **Assets** and download the archive named **`BinanceTradeBot`**.
2. Extract the complete archive to a writable folder.
3. Keep the included companion files together and configure the application according to `README.md` or `README.ru.md`.
4. Double-click **`BinanceTradeBot-Windows-x64.exe`** inside the extracted folder.

The automatically generated **Source code** archives contain source files rather than the Windows application package.

## Configuration and compatibility

The source configuration template is `.user.cfg.example`; save a local copy as `user.cfg`. The template contains blank credentials and `testnet=true`. Review `supported_coin_list` and the release's build-specific requirements before running the application.

The maintainer should document the source revision used for the executable, supported Windows versions, build process, and test results. This description does not establish verified compatibility or new trading features.
